EcoSight

Ecosight is an instrument with the objective of analysing and representing common trash types in different regions. Acting as a tool for waste management, this model will interpret and map the most common types of waste, encouraging creative solutions on how to effectively dispose, recycle, and sort common trash types in a given area. This project combines artifical intelligence with envrionmet sustainability by using an AI module to recognise trash types and log it into a heat map
